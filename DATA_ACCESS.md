# Data access and sharing

This repository does not distribute MIMIC-IV data or patient-level derived data.

The analysis used MIMIC-IV version 3.1, available from PhysioNet after completion of the credentialing process, required training and the MIMIC-IV data use agreement:

https://physionet.org/content/mimiciv/3.1/

Users must obtain their own authorised access and run the code in an environment that complies with the PhysioNet data use agreement. Raw records, row-level extracts, patient identifiers, timestamps, analytic cohorts, cloned records, weights and bootstrap samples must not be uploaded to GitHub.

The code uses only de-identified MIMIC-IV identifiers during local execution. These identifiers are still part of the restricted dataset and are therefore excluded from this repository.
