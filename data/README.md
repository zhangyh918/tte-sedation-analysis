# Data directory

No study data are included in this repository.

Do not place raw or derived MIMIC-IV records in a Git-tracked directory. This includes CSV, RDS, Parquet, Feather, database dumps, row-level model outputs, clone histories, inverse-probability weights and bootstrap samples.

Credentialed users should keep all record-level files in a separate restricted directory outside the repository and provide their paths only through local, untracked configuration.
